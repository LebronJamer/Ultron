# Ultron

A local, offline-first **voice assistant for Windows** with an Ultron-inspired
machine voice, full system control, and a free local AI brain — packaged as a
professional `setup.exe`.

👉 **Everything lives in [`UltronV1/`](UltronV1/README.md)** — code, installer
script, and build tooling. The CI workflow that produces the `.exe` installer
is at [`.github/workflows/build-installer.yml`](.github/workflows/build-installer.yml)
(GitHub requires workflows at the repo root).

**Get the installer:** Actions tab → *Build Ultron Windows Installer* → latest
run → artifact `Ultron-Windows-Setup`, or push a `v*` tag to auto-publish a
GitHub Release with the setup.exe attached.
